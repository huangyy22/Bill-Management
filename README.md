# 拾账｜报销管理

我的拾账报销平台：给 Windows 个人使用的本地桌面报销助手。文件仅保存于当前电脑，不上传云端。

## 直接运行

- 双击桌面上的“拾账 · 报销管理”快捷方式，或运行打包目录中的 `拾账.exe`。请正常双击启动；以管理员身份运行时，Windows 会阻止从普通资源管理器拖入文件。
- 若要手动开发或构建：安装 Node.js 22.12 或更高版本，执行 `npm install`、`npm start`。

首次启动自动使用 `文档\报销` 目录，并创建隐藏子文件夹 `.拾账` 存放可恢复的金额补记和撤销记录；不会自动移动或更改任何现有凭证。若目录不存在，应用会创建它。点击左下角可打开实际目录。

## 使用

1. 点“新建报销项目”，例如 `2026.10.20报销`。
2. 把 PDF、照片等文件拖到窗口，或点“添加凭证”。普通 PDF 读取内嵌文字；图片使用 Windows OCR，漏识别的数字由内置离线 OCR 补充，并按原位置匹配交易金额，避免把余额当费用。选择归档项目，在预览中核对；未识别的内容手动填写。
3. 自动区分出租车与网约车，并识别凭证类型；例如 `网约车-发票-40.pdf`、`网约车-行程单-40.pdf`。高铁票会识别并允许修改行程，例如 `高铁（长沙南-杭州东）-437.pdf`；不同方向、车次或乘客的同价车票仍各记一笔。同名自动加 `(2)`、`(3)`，预览会结合目标文件夹已有文件显示序号。一笔包含发票、行程单、付款截图等时选择“多份附件合为一笔”，创建带总金额的子文件夹，只计一次金额；两份同类同价、不同类型的凭证会显示快捷合并按钮。相同内容的文件会提示重复，不覆盖同名文件；也可对全部清楚的条目开启自动归档。
4. 费用文件夹会显示凭证完整性：出租车检查付款记录；网约车检查发票、付款记录和行程单；住宿检查发票和付款记录；高铁检查车票和付款记录。完整时显示“✓ 凭证完整”，否则直接列出缺少项。文件和费用文件夹都可在软件内改名并撤回。
5. 点击“标记已报销”将整个项目移入 `报销\已报销`，需要时可恢复。操作记录支持安全撤回。
6. 报销金额以项目名或费用文件夹名末尾的 `-金额` 为基础；有明确金额的文件夹不会重复累加其子凭证。同名压缩包与解压文件夹也不会重复计数。向已有金额的文件夹新增费用时，应用在 `.拾账` 中保存新增金额，显示“原标注 + 新增”后的总额，原有文件夹名称保留。CSV 导出功能只导出清单，不修改源凭证。迁移或备份时请连同 `.拾账` 一起保留。

在项目内，每个文件和费用文件夹右侧都有“改名”，操作可从记录中撤回。项目首页的“导出打印文件夹”会将项目下的全部凭证扁平复制到 `报销\导出打印\项目名-打印包`；所有凭证直接位于同一层，可在资源管理器中全选打印。同名文件自动添加 `(2)`、`(3)`，不会覆盖；导出的副本不显示在项目列表，也不会重复计入金额。

若不同凭证被识别为相同类别、相同金额，应用会提醒检查是否应合并。勾选“可靠识别后自动归档”后，后续拖入的明确凭证会在识别后等待 3 秒自动剪切；修改内容或关闭导入窗口即可取消。本项默认关闭；多金额、类别不明和多份附件合为一笔时需手动核对确认。未选项目时不会自动决定去向。

## 验证与打包

- `npm test` 运行金额识别、去重、改名、归档、撤回和状态流转测试。
- `npm run pack` 创建 Windows x64 免安装应用至 `dist`。可复制应用目录中的 exe 快捷方式至桌面；无需安装管理员级软件。首次构建会下载 Electron 运行时。
- 应用设置单实例锁，不保存 OCR 识别原文。

如希望每周备份已归档文件，请在 Windows 文件历史记录中包括 `Documents\报销` 文件夹。此应用不会将本地凭证上传或备份至网络。
